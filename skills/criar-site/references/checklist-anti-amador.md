# Checklist anti-amador

Aplique a cada seção antes de seguir para a próxima [P-12]. Os itens marcados com ✓ são cobertos pelo verificador; os demais são revisão sua, e a resposta vai para o relatório final.

## Cor

- [ ] A paleta é a do design system. Nada de roxo, rosa ou degradê azul "padrão de IA" que não esteja nele. ✓ (B4)
- [ ] Há uma cor dominante e um acento usado com parcimônia: botões principais, números-chave, foco.
- [ ] Texto atinge o contraste AA. ✓ (B10)

## Tipografia

- [ ] Títulos usam a fonte e o estilo de título do design system, com a entrelinha e o espaçamento originais.
- [ ] No máximo duas famílias, as do design system. ✓ (B4)
- [ ] A hierarquia é clara: um h1 e níveis sem saltos. ✓ (B9)
- [ ] Nenhuma linha de texto corrido passa de cerca de 75 caracteres.

## Composição

- [ ] As seções não se parecem com blocos empilhados: há variação de grade, alinhamento ou densidade entre elas.
- [ ] Os fundos têm profundidade quando o design system tem (gradiente, textura, linhas, brilho). Nada de fundo chapado onde a referência tinha atmosfera.
- [ ] O espaço vazio tem intenção. Nenhum bloco grande vazio só porque faltou conteúdo.
- [ ] Os cortes entre seções seguem o padrão da referência (divisor, mudança de fundo, sobreposição).

## Movimento

- [ ] Existe pelo menos uma entrada animada e estados de hover do design system. ✓ (B5)
- [ ] O movimento guia o olhar e não distrai: revelações escalonadas e uma animação contínua no máximo por tela.
- [ ] Há `prefers-reduced-motion`. ✓ (B10)

## Conteúdo

- [ ] Cada seção tem um único propósito, escrito no plano.
- [ ] Os botões dizem a ação ("Agendar demonstração"), não "Clique aqui".
- [ ] Os marcadores provisórios estão visíveis e listados no relatório.
